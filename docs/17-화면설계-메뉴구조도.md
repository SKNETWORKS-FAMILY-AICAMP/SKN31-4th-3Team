## 1. 메뉴 구조도 (IA)

```
Eden
│
├─ L1  인트로                    /intro          [비로그인 가능]
│   └─ L2  건너뛰기 → 홈
│
├─ L1  홈                        /home           [비로그인 가능]
│   ├─ L2  질문 입력
│   ├─ L2  추천 질문 칩
│   └─ L2  MBTI 레일 (오른쪽, 상주)
│
├─ L1  답변                      /ask?q=…        [비로그인 가능]
│   ├─ L2  공감 · 묵상
│   ├─ L2  구절 카드 ×3
│   │   ├─ L3  구절 열기        → /sky?focus=…&travel=1
│   │   └─ L3  다른 구절 보기
│   └─ L2  은하 찾아가기        → /sky?galaxy=…&travel=1
│
├─ L1  별자리                    /sky            [비로그인 가능]
│   ├─ L2  캔버스 (드래그 · 별 클릭 · 은하 클릭)
│   ├─ L2  키보드 순회
│   └─ L2  구절 상세 (오버레이)  /verse/:id
│       ├─ L3  구절 · 맥락 · 묵상
│       └─ L3  상담 이어가기    → /counsel?from=…
│
├─ L1  상담                      /counsel        [로그인 필요]
│   ├─ L2  대화 스레드
│   │   ├─ L3  답변 복사
│   │   └─ L3  안전 안내 (조건부)
│   ├─ L2  입력창
│   └─ L2  상징 배지 (인물)
│
├─ L1  계정                      /auth           [비로그인]
│   ├─ L2  로그인
│   └─ L2  회원가입 (이름 · 이메일 · 비밀번호 · MBTI)
│
├─ L1  회원정보                  /account        [로그인 필요]
│   ├─ L2  이름 · MBTI 수정
│   ├─ L2  로그아웃
│   └─ L2  탈퇴 (2단계 확인)
│
├─ L1  환경설정                  /settings       [비로그인 가능]
│
└─ L1  사이드바 (전역, 왼쪽 위 ☰)
    ├─ L2  메뉴 — HOME · 별자리 · 구절 목록
    │   └─ L3  구절 목록 창 (은하 탭 13 + 구절 목록)
    ├─ L2  지난 상담 목록        [로그인 필요]
    │   ├─ L3  대화 열기
    │   └─ L3  나가기 (2단계 확인)
    └─ L2  하단 — 환경설정 · 계정
```

### 접근 제어

| 깊이 | 비로그인 | 로그인 |
|---|---|---|
| 인트로 · 홈 · 답변 · 별자리 · 구절 상세 | ✅ | ✅ |
| 상담 | ❌ → `/auth?then=…` | ✅ |
| 지난 상담 목록 | 비어 있음 | ✅ |
| 회원정보 | ❌ | ✅ |

> **왜 상담만 막는가** — 대화는 사용자의 기록이므로 저장할 곳이 있어야 하고,
> 남의 것을 열어서도 안 된다. 질문과 탐색까지는 입구를 열어 둔다.

## 3. LLM 상호작용 상태 명세 ← 평가 항목

### 3.1 상태 전이

```
 [1] 입력 전
   │  전송
   ▼
 [2] 대기 (첫 조각 전)
   │  첫 조각 도착              연결 실패 / 15초 초과
   ▼                                    │
 [3] 스트리밍 수신 중                    ▼
   │  [DONE]                        [5] 오류
   ▼                                    │  다시 시도
 [4] 완료 ──────────────────────────────┘
```

### 3.2 상태별 UI

| 상태 | 입력창 | 전송 버튼 | 말풍선 | 복사 | 그 밖 |
|---|---|---|---|---|---|
| **[1] 입력 전** | 활성 | 활성 (내용 있을 때) | — | — | 추천 질문 칩 |
| **[2] 대기** | 비활성 | 비활성 | "마음을 살피는 중…" + 점 3개 | 숨김 | `role="status"` 로 읽힘 |
| **[3] 스트리밍** | 비활성 | 비활성 | 글자가 차례로 붙는다 | **숨김** | 자동 스크롤 (사용자가 위로 올리면 멈춤) |
| **[4] 완료** | 활성 | 활성 | 완성된 답변 | **노출** | 출처 구절 표시 |
| **[5] 오류** | 활성 | 활성 | 받은 데까지 유지 | 숨김 | 원인 문구 + 다시 시도 |

> **[3] 에서 복사를 숨기는 이유** — 받는 중인 말을 복사하면 잘린 문장이
> 클립보드에 들어간다. 그건 실패보다 알아채기 어렵다.

### 3.3 오류 문구 — 원인별로 다르게

| 원인 | 문구 | 사용자가 할 일 |
|---|---|---|
| 15초 초과 | "응답이 늦어 멈췄습니다. 잠시 뒤 다시 시도해 주세요." | 기다렸다 재시도 |
| 네트워크 끊김 | "연결이 끊어졌습니다. 네트워크를 확인해 주세요." | 연결 확인 |
| 서버 오류 | "답변을 받지 못했습니다. 다시 시도해 주세요." + 서버 원인 | 재시도 |
| 대화 생성 실패 | "대화를 시작하지 못했습니다." + 원인 | 다시 시작 |
| 화면 이탈 | (문구 없음) | — 사용자가 그만둔 것이지 실패가 아니다 |

> **취소를 오류로 표시하지 않는다** — 시간 초과와 사용자 취소는 둘 다
> `AbortError` 로 온다. 구분하지 않으면 화면을 떠난 사람에게 "응답이
> 늦습니다" 를 띄우게 된다.

## 4. 반응형 설계 ← 평가 항목

### 4.1 브레이크포인트

| 폭 | 이름 | 변화 |
|---|---|---|
| ~640px | 모바일 | 여백 축소, 헤더 공간 108→88px, 카드 모서리 완화 |
| ~720px | 소형 | **오른쪽 MBTI 레일 접힘** (목록으로 같은 탐색) |
| 721px~ | 데스크톱 | 레일 노출 |

| 높이 | 변화 |
|---|---|
| ~620px | 레일 접힘 (16줄이 화면을 넘는다) |
| 621~820px | 레일 간격·자간 축소, 상태 문구 숨김 (**기능은 유지**) |
| 821px~ | 기본 |

> **기능을 없애기 전에 먼저 줄인다** — 820px 구간에서 숨기지 않고 압축하는
> 이유다.

### 4.2 데스크톱 vs 모바일

**별자리 화면**

| | 데스크톱 | 모바일 |
|---|---|---|
| MBTI 레일 | 오른쪽 세로 16줄 | 숨김 |
| 구절 찾기 | 사이드바 → 목록 창 | 동일 |
| 안내 문구 | 하단 중앙 알약 | 하단, 모서리 완화 |
| 시점 회전 | 드래그 | 터치 드래그 |

**상담 화면**

| | 데스크톱 | 모바일 |
|---|---|---|
| 사이드바 | 왼쪽에서 밀려 나옴 (겹침) | 동일. 폭 `min(19rem, 84vw)` |
| 상징 배지 | 대화 옆 | 상단 |
| 복사 버튼 | hover 시 노출 | **항상 옅게** (터치엔 hover 가 없다) |
| 입력창 | 하단 고정 | 하단 고정 + `safe-area-inset` |

### 4.3 Flex/Grid 사용

| 자리 | 방식 | 이유 |
|---|---|---|
| 화면 셸 | `flex-column` + `min-height: 100dvh` | 하단 고정 요소가 안정적으로 붙는다 |
| MBTI 레일 | `flex-column` + `max-height: calc(100dvh - …)` | 넘치면 안에서만 스크롤 |
| 은하 탭 | `flex-wrap` | 13개가 두세 줄로 접힌다 (가로 스크롤은 뒤쪽을 숨긴다) |
| 사이드바 | `flex-column` (메뉴 고정 / 목록 `flex:1` / 하단 고정) | 대화가 쌓여도 계정 버튼이 밀려나지 않는다 |
| 구절 목록 창 | `flex-column` (머리 고정 / 목록 `flex:1`) | 은하를 바꾸려고 위로 스크롤하지 않게 |
| 구절 카드 | `grid` | 카드 수가 달라져도 배치가 유지된다 |

> **`dvh` 를 쓰는 이유** — 모바일 브라우저의 주소창이 접혔다 펴질 때 `vh` 는
> 화면 높이를 잘못 잡아 목록이 잘린다.

### 4.4 겹침을 막은 방식

MBTI 레일은 `position: fixed` 라 문서 흐름에서 사라진다. 화면 콘텐츠는
그 자리가 비어 있다고 믿고 가운데 정렬하므로, 폭이 줄면 겹친다.

두 가지를 시도했다.

1. **화면에 여백을 준다** — 겹침은 사라졌지만 화면 전체가 왼쪽으로 밀려
   가운데 정렬된 것들이 가운데가 아니게 됐다. **되돌렸다**
2. **겹칠 것을 없앤다** — 구절 목록을 별도 창으로 옮겨 하늘 위에는 안내
   문구 한 줄만 남겼다. **이쪽을 택했다**

## 5. 인증 상태별 화면 변화

| 요소 | 비로그인 | 로그인 |
|---|---|---|
| 우측 상단 | "로그인" · "회원가입" | `{이름} {MBTI}` (누르면 회원정보) |
| 사이드바 하단 | "로그인" | `{이름}님` |
| 사이드바 지난 상담 | "이야기를 시작하면 여기에 남습니다" | 대화 목록 |
| MBTI 레일 | 밑줄만 (선택 표시) | 내 유형이 **은은히 빛난다** |
| 홈 인사 | 기본 문구 | "{이름}님, 어서 오세요" |
| 상담 진입 | `/auth?then=…` 로 | 바로 입장 |

### 토큰 만료 시

1. 화면에는 아무 변화가 없다 — 자동 갱신이 조용히 일어난다
2. 갱신도 실패하면 로그아웃 상태로 바뀌고 로그인 화면으로
3. 돌아올 곳을 `?then=` 에 담는다 (`internalPath()` 로 검증)

## 6. 디자인 원칙

| 원칙 | 적용 |
|---|---|
| 절제된 흑백 | 은백색 · 달빛색 · 따뜻한 백색만 미세하게 |
| 폰트 | 본문 Pretendard(산세리프). 세리프는 인트로·조우에만 |
| 판을 두지 않는다 | MBTI 레일은 배경·테두리 없이 글자만 |
| 조용한 움직임 | 별 반짝임 2.4~7.8초, MBTI 호흡 7초 — 알아채기 직전의 속도 |
| 입력을 막지 않는다 | 모든 연출에 건너뛰기 |
| 상징은 추상적으로 | 십자가·열쇠·조개를 별의 배치로 (이미지 없음) |
