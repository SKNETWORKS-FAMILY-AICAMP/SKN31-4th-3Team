# Eden — 프론트엔드 · 백엔드 합병 결과

회의·발표용 요약. 5분 분량입니다.

---

## 한 줄

**React 프론트엔드와 Django 백엔드를 하나로 합쳤고, 백엔드는 Django 단일로 정리했습니다.**
394개 테스트가 통과하며, AWS 배포 구성까지 준비됐습니다. LLM 은 아직 붙지 않았고,
붙일 자리는 함수 하나로 좁혀 두었습니다.

---

## 1. 무엇이 달라졌나

| | 전 | 후 |

## 2. 눈에 보이는 것

- 인트로 → 은하수 → 구절 → 상담까지 **실제 데이터로** 흐릅니다.
- 은하 13개(예수 그리스도 + 12제자), 구절 **702개**가 DB 에 있습니다.
- 로그인하면 대화가 저장되고 다음에 이어집니다.
- MBTI 를 고르면 결이 가까운 은하만 남습니다 — 궁합 값은 팀의
  `mock_data.py` 행렬을 그대로 씁니다.

---

## 3. 눈에 안 보이는 의사결정 4가지

### ① 백엔드를 하나로 모았다

서비스가 둘이면 배포 대상, 인증 경계, 장애 지점, AWS 비용이 전부 두 벌이
됩니다. FastAPI 쪽에 있던 것은 도메인 데이터와 키워드 매칭이었고, Django
앱으로 옮기는 데 제약이 없었습니다.
→ **RAG 를 실제로 붙일 때 다시 분리를 검토합니다.** 지금 나누면 얻는 것
없이 운영만 복잡해집니다.

### ② 구절 데이터를 사람이 옮기지 않았다

702개를 손으로 베끼면 반드시 어긋나고, **어긋나도 티가 안 납니다.**
프론트 데이터를 읽어 JSON 으로 뽑는 스크립트를 만들었고, Django 는 그
JSON 만 적재합니다.
→ 원본은 하나, 옮기는 일은 자동. 프론트를 고치면 명령 두 줄로 반영됩니다.

### ③ 좌표는 서버에 두지 않았다

별의 화면 좌표는 프론트가 "은하 안 순번"에서 계산합니다. 서버가 좌표까지
들고 있으면 배치 규칙을 고칠 때마다 DB 를 다시 써야 하고, 두 규칙이
어긋나는 순간 별이 성운 밖에 뜹니다.
→ 서버의 책임은 `order` 까지.

### ④ 위기 판정을 클라이언트에 남겼다

자해·위기 신호 판정은 **서버로 옮기지 않았습니다.** 서버가 죽거나 네트워크가
끊겨도 안전 안내는 떠야 합니다. 프론트가 요청 이전에 먼저 판정하고, 위기로
보이면 API 를 호출하지 않습니다. 서버 판정은 그 위에 한 겹 더 두는 것이고,
대체가 아니라 추가입니다.

## 4. 합병하다 발견한 문제

| 발견 | 조치 |
|---|---|
| `requirements.txt` 의 `Django==6.0.7` — **존재하지 않는 버전** | 5.2 LTS 로 수정. 그대로 두면 Docker 빌드가 첫 줄에서 멈춥니다 |
| `ALLOWED_HOSTS = []`, `SECRET_KEY` 없으면 크래시 | 환경변수화 + `.env.example` |
| `DATABASE_URL` 없으면 실행 불가 | SQLite 폴백 — `git clone` 후 바로 돌아갑니다 |
| `STATIC_ROOT` 미설정 | `collectstatic` 대상 지정 |
| API 남용 제한 없음 | Throttle 익명 60/분, 로그인 120/분 |
| 헬스체크 없음 | `/healthz/` (DB 를 건드리지 않음) |

## 5. 남은 일

| 우선순위 | 항목 | 붙일 자리 |
|:---:|---|---|
| **1** | **연관 구절 662개의 성경 본문** | 저작권 확인 전이라 요약만 있음. `Verse.excerpt` 채우면 끝 |

본문을 보려면 성경을 따로 펴야 합니다.

## 6. 비용

**월 약 $40** (EC2 t3.small + RDS db.t4g.micro + S3 + CloudFront)
프리 티어면 사실상 **$1 내외**. 데모 후 EC2 중지 + RDS 스냅샷 후 삭제하면 거의 0.

주의: NAT Gateway(월 $35)를 만들지 마세요. 이 구성에서는 필요 없습니다.

---

## 7. 지금 해볼 수 있는 것

```bash
docker compose up --build     # → http://localhost
```

- `http://localhost` — 전체 서비스
- `http://localhost/api/v1/docs/` — Swagger

백엔드 없이 화면만 보려면 `cd frontend && npm run dev`
(`VITE_API_BASE_URL` 이 없으면 자동으로 mock 으로 돕니다).
