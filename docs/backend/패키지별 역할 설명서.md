## Django 6.0+ 프로젝트 적용 시 유의사항 및 팁
- **파이썬 버전 요구사항**:
Django 6.x 버전부터는 Python 3.12 이상 사용을 권장/요구합니다. 개발 환경의 파이썬 버전을 미리 체크해 주세요. (python --version)
- **비동기(Async) 및 SSE 지원 강점**:
Django 6.0은 비동기 ORM 및 스트리밍 응답(StreamingHttpResponse) 처리가 더욱 안정화되어 있어, LLM 토큰 단위 스트리밍 응답 구현 시 uvicorn 기반 ASGI 실행 환경과의 궁합이 뛰어납니다.
- **환경 공유 실무 팁**:
로컬에서 패키지 설치 완료 후 pip freeze > requirements.txt 명령어를 실행하면 현재 6.0.7 버전을 포함한 실제 설치된 정확한 의존성 버전들이 한 번에 텍스트 파일로 출력됩니다.

## 패키지별 주요 역할 설명
- **Django / DRF / CORS**: RESTful API 구축 및 React 개발 서버 연동을 위한 Cross-Origin 설정
- **django-environ**: .env 파일의 API Key, DB 접근 비밀번호 등 환경변수를 안전하게 로드
- **djangorestframework-simplejwt**: JWT 기반 Access / Refresh 토큰 인증 처리
- **openai / langchain**: LLM 모델 연동 및 대화 맥락(Context) 관리
- **drf-spectacular**: React 프론트엔드 팀과의 협업을 위한 Swagger API Docs 자동 생성
- **uvicorn / gunicorn**: SSE(Server-Sent Events) 비동기 스트리밍 응답 처리를 고려한 ASGI/WSGI 서버 지원
