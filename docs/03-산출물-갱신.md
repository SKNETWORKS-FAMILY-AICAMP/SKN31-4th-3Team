### 4.3 프론트 테스트 중 회귀 방지 항목

실제로 발생했던 버그를 테스트로 고정한 것들입니다.

| 테스트 | 막는 버그 |
|---|---|
| 비네트 `pointer-events: none` | 별 클릭이 장식 레이어에 먹힘 |
| 캔버스 `user-select: none` | 드래그 시 페이지 전체 글자가 선택됨 |
| 감쇠 기준이 은하 크기와 무관 | 위성 은하 별자리 선이 5% 만 보임 |
| 도착 구도가 은하마다 동일 | 위성 은하 확대가 1.27배에 그침 |
| 별자리에 섬이 없음 | 두 개씩 끊긴 짝이 흩어짐 |
| 닫기 경로에 focus 없음 | 확대된 채로 멈춤 |
| MBTI 목록이 포인터를 통과 | 뒤의 별을 누를 수 없음 |

### 4.4 아직 자동화하지 않은 것

| 항목 | 지금 | 계획 |
|---|---|---|
| E2E (브라우저) | 수동 | Playwright — 인트로→질문→상담 시나리오 |
| 캔버스 시각 회귀 | 수동 | 스크린샷 비교 |
| 부하 테스트 | 없음 | Locust — `/scripture/verses/` 와 `/ask/` |
| 접근성 자동 검사 | 부분(ARIA 단언) | axe-core 통합 |

### 4.5 수동 확인 항목 (배포 전)

```
□ 인트로 25초 재생 + 건너뛰기
□ 별 클릭 → 비행 → 상세 → 닫기 → 초기 시야 복귀
□ 드래그 회전 중 텍스트 선택이 일어나지 않음
□ MBTI 선택 시 프레임 유지, 해제 시 순차 복귀
□ 로그인 → 상담 → 새로고침 후 로그인 유지
□ /verse/gen-1-3 직접 접속(새로고침) 정상
□ 위기 키워드 입력 시 안전 안내 (네트워크 끊고도 확인)
□ 모바일 360px 폭에서 레이아웃 깨짐 없음
□ prefers-reduced-motion 켜고 정적 연출 확인
```

## API 규약 명세서 (증분)

기존 명세는 `users`(4개) · `chat`(4개) 였습니다. 다음이 추가·변경됩니다.

### 추가

| 기능 | Method | URL | 권한 |
|---|:---:|---|---|
| 은하 목록 | GET | `/api/v1/scripture/galaxies/` | 공개 |
| 구절 목록 | GET | `/api/v1/scripture/verses/` | 공개 |
| 구절 상세 | GET | `/api/v1/scripture/verses/{slug}/` | 공개 |
| 고민 → 추천 | POST | `/api/v1/scripture/ask/` | 공개 |

### 변경

| 대상 | 기존 | 변경 |
|---|---|---|
| `POST /auth/register/` | email, username, password | **+ mbti (선택)** |
| `GET /auth/me/` | 조회만 | **+ PATCH (mbti 변경)** |
| `ChatSession` | user, title | **+ seed_verse, seed_question** |
| `ChatMessage` | session, role, content | **+ verse (근거 구절)** |
| `GET /chat/sessions/{id}/messages/` | 페이지네이션 | 페이지 없음 (대화는 통째로 읽음) |
| 전체 | 제한 없음 | **Throttle** 익명 60/분, 로그인 120/분 |

상세 스키마는 `/api/v1/docs/` (Swagger) 에서 항상 최신입니다.
`docs/01-통합-설계서.md` 5장에 요청·응답 예시가 있습니다.
