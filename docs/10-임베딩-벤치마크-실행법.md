# 임베딩 벤치마크 실행법

목적: **어느 임베딩 모델 × 어느 청킹 방식**으로 성경 검색을 만들지를 숫자로 정한다.

---

## 0. 한 줄 요약

```bash
cd server
python scripts/bench_embeddings.py --models small large \
    --strategies verse window1 window2 sliding --out bench.json
```

표본 8,000절 기준 8칸 전부 합쳐 **약 $0.1**, 시간은 5~10분.

---

## 1. 준비 (한 번만)

### 가상환경 켜기

```bash
cd server
source .venv/bin/activate        # Windows: .venv\Scripts\activate
```

`pip -V` 했을 때 경로에 `.venv` 가 들어 있어야 합니다. 없으면 그 자리에서 만듭니다.

```bash
python -m venv .venv && source .venv/bin/activate
```

### 패키지 설치

```bash
pip install -r requirements.txt
```

`openai` 와 `django-environ` 이 여기 들어 있습니다.

### 키 확인

`server/.env` 에 이 줄이 있으면 됩니다. 스크립트가 `.env` 를 직접 읽으므로 따로 `export` 하지 않아도 됩니다.

```
OPENAI_API_KEY=sk-...
```

### 무엇을 쓸 수 있는지 확인

```bash
python scripts/bench_embeddings.py --list
```

```
이름         상태     모델
────────────────────────────────────────────────────
hash       준비됨    hash-baseline
large      준비됨    text-embedding-3-large
qwen0.6b   없음     Qwen3-Embedding-0.6B
small      준비됨    text-embedding-3-small
voyage     없음     voyage-3
```

`small` 과 `large` 가 **준비됨** 이면 시작할 수 있습니다.

## 2. 먼저 하네스가 도는지 확인 (돈 안 듦)

```bash
python scripts/bench_embeddings.py --models hash --strategies verse
```

30초쯤 걸리고 이렇게 나오면 정상입니다.

```
═══ 지시적 검색 (구절 찾기) ═══
hash-baseline   verse    R@1 0.133  …  nDCG@10 0.195

═══ 상담 검색 (실사용) ═══
hash-baseline   verse    R@1 0.000  …  nDCG@10 0.000
```

`hash` 는 **의미를 전혀 모르는 가짜 벡터**입니다. 바닥값이고, 진짜 모델은 이걸 크게 넘어야 합니다. 상담 검색이 0.000 인 것이 정상입니다 — 그 정답셋은 어휘 겹침으로는 못 풉니다.

> 진짜 모델의 점수가 이것과 비슷하게 나오면, 모델이 나쁜 게 아니라 하네스나 정답셋이 잘못된 것입니다. 그때는 결과를 믿지 말고 알려 주세요.

## 3. 본 실행

```bash
python scripts/bench_embeddings.py --models small large \
    --strategies verse window1 window2 sliding --out bench.json
```

진행 중에 `… small × verse 임베딩 중` 이 8번 지나갑니다. 끝나면 표 두 개가 뜹니다.

### 결과 읽는 법

| 지표 | 뜻 |
|---|---|
| **R@3** | 화면에 구절 3개를 보여 주므로 **실사용에 가장 가까운 숫자** |
| **nDCG@10** | 가장 종합적. 정답이 위쪽에 몰려 있을수록 높음 |
| R@10 | "찾아는 지는가" |
| MRR@10 | 첫 정답이 몇 번째인가 |

**두 표를 모두 봅니다.** 지시적 검색은 모델 품질을 가르고, 상담 검색은 우리가 실제로 푸는 문제입니다. 둘이 다른 답을 가리키면 상담 쪽을 따릅니다.

## 5. Qwen 8B 를 내 노트북에서 돌리기

### 먼저 사양 확인

```bash
# macOS
system_profiler SPHardwareDataType | grep -E "Chip|Memory"

# Windows (PowerShell)
Get-CimInstance Win32_VideoController | Select Name, AdapterRAM
Get-CimInstance Win32_ComputerSystem | Select TotalPhysicalMemory
```

### 필요한 메모리

| 방식 | 크기 | 필요 조건 |
|---|---:|---|
| FP16 (원본) | 15.1 GB | GPU VRAM 16GB+ · Mac 32GB+ |
| **Q8_0** | **8.05 GB** | GPU 10GB+ · Mac 16GB+ — **권장** |
| Q4_K_M | 4.68 GB | GPU 6GB+ · Mac 16GB |

**Mac(Apple Silicon)은 통합 메모리라 유리합니다.** 다만 전부 쓸 수 있는 것은 아니고, macOS 가 GPU 에 기본 약 75% 까지만 내줍니다. 24GB 면 GPU 몫이 약 18GB 이고, 여기에 브라우저·에디터가 함께 올라갑니다.

| Mac 메모리 | GPU 몫(약) | 권장 |
|---:|---:|---|
| 16 GB | 12 GB | Q8 (8.05GB) |
| **24 GB** | **18 GB** | **Q8** — FP16 은 되지만 빠듯함 |
| 32 GB+ | 24 GB+ | FP16 도 여유 |

**Windows + NVIDIA 는 VRAM 만 셉니다.** RAM 이 64GB 여도 그래픽카드가 8GB 면 Q8 까지입니다.

### 시간을 먼저 재 보세요

8B 는 OpenAI API 와 달리 내 기기가 계산합니다. 표본 8,000청크 × `window2` 면 토큰이 200만 개쯤 되고, M4 Pro 기준 **30분~1시간**이 걸릴 수 있습니다(정확한 값은 기기마다 다릅니다).

그래서 4가지 청킹을 한 번에 돌리지 말고 하나만 먼저 재 보세요.

```bash
time python scripts/bench_embeddings.py --models q8 --strategies verse
```

`verse` 는 글이 가장 짧아 제일 빠릅니다. 이걸로 감을 잡은 뒤 `window2` 를 돌리세요. 임베딩은 캐시되므로 중간에 끊겨도 다시 처음부터 하지는 않습니다.

### Ollama 로 돌리기 (권장)

`sentence-transformers` 보다 이쪽이 쉽습니다. torch 를 설치하지 않고, GPU 메모리가 모자라면 남는 층을 알아서 CPU 로 흘립니다.

**Ollama 는 파이썬 패키지가 아닙니다.** `pip install ollama` 는 클라이언트 라이브러리라 본체가 아닙니다. 백그라운드에서 도는 별도 앱입니다.

```bash
# 1. 설치
brew install --cask ollama       # 앱 (메뉴바에서 자동 실행)
#   또는
brew install ollama              # 실행 파일만 — 서버를 직접 띄워야 함

# 2. 서버 띄우기 (cask 로 깔았고 앱을 실행했다면 건너뜀)
ollama serve                     # 터미널 탭 하나를 차지한다. 켜 둘 것
#   또는 백그라운드 서비스로
brew services start ollama

# 3. 서버가 떴는지 확인
curl -s localhost:11434/api/tags && echo "  ← 정상"

# 4. 모델 받기 — ★ 공식 라이브러리 태그를 쓸 것
ollama pull qwen3-embedding:8b                   # 약 5GB (Q4_K_M)

# 5. 하네스가 인식하는지 확인
python scripts/bench_embeddings.py --list        # oll8b 이 "준비됨" 이면 성공

# 6. 돌리기
python scripts/bench_embeddings.py --models oll8b --strategies window2
```

> **커뮤니티 변환본(`dengcao/...`)은 임베딩이 안 될 수 있습니다.** GGUF 에 `pooling_type` 메타데이터가 없으면 Ollama 가 생성 모델로 취급해 `/api/embed` 에 **501** 을 돌려줍니다. [알려진 문제](https://github.com/ollama/ollama/issues/12757)이고, 공식 `qwen3-embedding:*` 태그에는 그 메타데이터가 들어 있습니다.

> 하네스는 `ollama` 명령을 쓰지 않고 `localhost:11434` 로 HTTP 요청만 보냅니다. **서버만 떠 있으면** CLI 가 PATH 에 없어도 됩니다.

### 양자화가 검색 품질을 깎지는 않나

깎습니다. 다만 **얼마나 깎는지는 추측하지 말고 재면 됩니다.**

"Q4 는 Q8 대비 4% 차이" 같은 이야기는 대개 문장 생성 기준입니다. 임베딩은 숫자 자체가 결과라, 미세한 값 변화가 코사인 유사도 순위를 바꿉니다. 그래서 둘 다 후보에 넣어 두었습니다.

공식 8B 태그는 Q4_K_M 입니다. 더 정밀한 Q8 을 재 보고 싶으면 커뮤니티 변환본을 받아 보세요 — **다만 위의 501 문제로 안 될 수 있습니다.**

```bash
ollama pull dengcao/Qwen3-Embedding-8B:Q8_0
python scripts/bench_embeddings.py --models oll8b q8 --strategies window2
```

`q8` 이 501 로 실패하면 그건 우리 잘못이 아니라 그 변환본 문제입니다. 공식 Q4 만으로 판단하셔도 충분합니다.

### 그래도 안 돌아가면

```bash
ollama pull qwen3-embedding:0.6b
python scripts/bench_embeddings.py --models oll0.6b --strategies window2
```

0.6B 로 계열 감만 잡고 판단하세요.

> **한 가지 짚어둘 것** — 로컬에서 8B 가 돌아도, EC2 t3.small(2GB)에는 못 올립니다. 8B 를 실제 서비스에 쓰려면 GPU 인스턴스(월 $200~)나 호스팅 API 가 필요합니다. 벤치마크에서 8B 가 이기더라도, **"이길 만큼 이겼는가"** 를 비용과 함께 봐야 합니다. OpenAI small 과 차이가 근소하면 답은 정해져 있습니다.

### 원본 가중치로 돌리고 싶다면

```bash
pip install sentence-transformers
python scripts/bench_embeddings.py --models qwen8b --strategies window2
```

첫 실행은 15GB 를 내려받습니다.

## 자주 나오는 문제

**`⊘ small 건너뜀 — 키 또는 패키지가 없습니다`**
`server/.env` 에 `OPENAI_API_KEY` 가 있는지, 그리고 `server/` 디렉터리에서 실행했는지 확인하세요. 스크립트는 `server/.env` 를 찾습니다.

**`ModuleNotFoundError: No module named 'openai'`**
가상환경이 안 켜졌거나 `pip install -r requirements.txt` 를 안 한 것입니다. `pip -V` 로 경로를 확인하세요.

**같은 명령을 다시 돌렸는데 즉시 끝남**
정상입니다. 임베딩은 `server/.embed-cache/` 에 쌓이고 같은 조합은 다시 부르지 않습니다. 강제로 다시 하려면 그 폴더를 지우세요.

**`Error: could not connect to ollama server, run 'ollama serve' to start it`**
실행 파일은 있는데 서버가 안 떠 있습니다. 터미널 탭을 하나 더 열어 `ollama serve` 를 켜 두거나, `brew services start ollama` 로 등록하세요.

**`zsh: command not found: ollama`**
`pip install ollama` 를 하신 것일 수 있습니다. 그건 파이썬 클라이언트지 본체가 아닙니다. 위 5장의 설치 단계를 보세요.

**`⊘ oll8b 건너뜀 — 키 또는 패키지가 없습니다`**
`curl -s localhost:11434/api/tags` 로 서버부터 확인하세요. 응답이 없으면 서버가 안 떠 있는 것입니다.

**`✗ … 실패: … 는 임베딩을 지원하지 않습니다 (HTTP 501)`**
그 GGUF 에 `pooling_type` 메타데이터가 없어 Ollama 가 생성 모델로 취급하는 것입니다. 커뮤니티 변환본에서 흔합니다. 공식 태그로 바꾸세요.

```bash
ollama pull qwen3-embedding:8b
python scripts/bench_embeddings.py --models oll8b --strategies verse
```

**결과가 이상하다**
`bench.json` 을 그대로 공유해 주세요. 표만 보는 것보다 원자료가 낫습니다.
