## 6. 회고

**잘된 것**

- Repository 인터페이스를 먼저 세워 백엔드 대기 없이 프론트를 완성했다
- 세 DB(관계형·벡터·그래프)를 각자 잘하는 일에만 쓰도록 나눴다
- 외부 의존이 전부 죽어도 화면이 뜨는 구조 — 단일 실패점이 RDS 하나뿐

**어려웠던 것**

- 결함 12건 중 6건이 "코드는 맞는데 결과가 조용히 비어 있는" 종류였다.
  오류도 안 나고 화면도 멀쩡해서 테스트로 잡히지 않았다
- 그래서 로직이 아니라 **배관을 검사하는 테스트**를 따로 만들어야 했다
- 그래프 가중치는 세 번 고쳤다. 매번 짐작이 아니라 실측이 답을 줬다
