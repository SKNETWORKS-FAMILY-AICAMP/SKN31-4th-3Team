### 2. 알아서 떴는지 확인 (1분)

컨테이너는 `restart: unless-stopped` 라 스스로 올라옵니다. 확인만 합니다.

### 3. 모델 예열 ← **가장 중요**

```bash
time curl -s http://localhost:11434/api/embed \
  -d '{"model":"qwen3-embedding:8b","input":"예열"}' -o /dev/null
```

> **이걸 빼먹으면 발표 첫 질문이 1분 걸립니다.**
> 재시작하면 9GB 모델이 GPU 메모리에서 내려가 있고, 첫 요청이 그걸 다시
> 올린다. 결과는 똑같이 나오고 시간만 걸리기 때문에 "고장난 것처럼"
> 보인다. 발표장에서 그 1분은 아주 길다.

첫 실행은 30~60초, 두 번째부터 1초 미만이면 정상입니다.

## 이야기할 거리

숫자를 물어보면 쓸 수 있는 것들입니다.

- 성경 **31,077절** 전체를 임베딩해 pgvector 에 적재
- 임베딩 모델 **qwen3-embedding:8b** — EC2 GPU(T4) 에서 자체 구동
- 화면의 별 **2,652개** (사람이 고른 702 + 은하당 150씩 배정)
- 검색은 **벡터 + 주제 + 성격(tone) + 그래프** 네 층
- Neo4j 그래프: 인물 **2,861명**, 감정 연결 **29,813개**
- 그래프가 하는 일: 같은 감정을 **이겨 낸** 인물이 등장하는 구절을 올린다
  (겪기만 한 구절보다 위로가 된다)

**그래프가 왜 필요한가** 를 물으면:

> 임베딩은 "말이 비슷한 것" 을 찾습니다. 번아웃을 검색하면 잠언 24:10
> "네 힘이 미약함을 보임이니라" 가 올라옵니다. 낙심을 말하는 구절이라
> 문장은 비슷하지만, 그건 위로가 아니라 질책입니다. 그 차이는 본문이
> 아니라 관계가 압니다.

## 발표가 끝나면 — 그날 안에

과금을 멈추려면 **중지가 아니라 삭제**여야 합니다.

- [ ] RDS 스냅샷 만들고 → RDS **삭제**
- [ ] EC2 **종료(terminate)**
- [ ] EBS 볼륨이 남아 있으면 삭제
- [ ] AMI(`eden-gpu-ready`) · 스냅샷 정리
- [ ] **탄력적 IP 해제(release)** ← 안 쓰는 EIP 는 계속 과금됩니다
- [ ] Neo4j Aura 는 **지우지 마세요** — 팀원이 발표 후 재사용할 예정입니다
