# 요구사항 정의서

문서 버전 v1.0 · 작성 2026-08-07 · 대상 Eden (말씀의 별자리)

## ID 체계

```
FR-<도메인>-<번호>    기능 요구사항
NFR-<분류>-<번호>     비기능 요구사항
IF-<대상>-<번호>      인터페이스 요구사항
DATA-<번호>           데이터 요구사항
UI-<번호>             화면 요구사항
```

도메인: `AUTH` 인증 · `CHAT` 상담 · `SEARCH` 검색 · `EXPLORE` 탐색 · `SAFE` 안전

### IF-API-002 상세 — SSE 규격

**요청**

```http
POST /api/v1/chat/sessions/<id>/stream/
Authorization: Bearer <access>
Content-Type: application/json
Accept: text/event-stream

{ "message": "요즘 너무 지쳐요" }
```

**응답 (조각)**

```
data: {"content": "그 말씀"}

data: {"content": "을 들으니"}

data: [DONE]
```

**오류**

```
data: {"error": "LLM 스트리밍 실패: ..."}
```

**타임아웃 정책**

| 경로 | 타임아웃 | 이유 |
|---|---|---|
| 일반 REST | 15초 | 넘으면 정상 지연이 아니라 사고 |
| 완성 응답(`completion/`) | 45초 | LLM 이 통째로 답을 만든다 |
| 스트리밍(`stream/`) | 없음 | 긴 답변은 오래 열려 있는 것이 정상 |

## 5. 배포 요구사항

| ID | 요구사항 | 구현 |
|---|---|---|
| DEP-001 | GPU 인스턴스에서 임베딩 모델을 자체 구동한다 | EC2 g4dn.xlarge (T4) |
| DEP-002 | 모델을 메모리에 상주시킨다 | `OLLAMA_KEEP_ALIVE=-1` |
| DEP-003 | DB 를 애플리케이션과 분리한다 | RDS db.t4g.micro |
| DEP-004 | 재시작해도 주소가 유지된다 | 탄력적 IP |
| DEP-005 | nginx 가 정적 파일과 API 를 함께 서빙한다 | SPA 폴백 + `/api` 프록시 |
| DEP-006 | 컨테이너 하나로 배포한다 | `docker-compose.prod.yml` |
| DEP-007 | 배포 후 검색이 살아 있는지 확인한다 | `deploy.sh` 의 `search.ready()` |

> **DEP-007 이 있는 이유** — 컨테이너가 떠 있어도 임베딩이 없으면 검색은
> 조용히 폴백으로 떨어진다. 화면은 멀쩡하고 추천만 예전 표에서 나온다.
