## 3. 시스템 아키텍처 및 개요

 Django & React 기반 LLM 챗봇 서비스 웹 애플리케이션은 React SPA 프론트엔드, Django REST Framework 백엔드, OpenAI API를 연동하여 SSE 기반의 실시간 스트리밍 대화를 제공하는 서비스이다.

| 구성 요소 | 역할 | 기술 스택 | 대표 구현 위치 |
|---|---|---|---|
| Frontend | 사용자 인증 UI, 챗봇 대화 화면, SSE 수신 및 타이핑 효과, 마이페이지 | React, Vite, Axios | `frontend/src/` |
| Backend | 회원 인증/인가(JWT), REST API, 대화 세션/히스토리 관리, LLM 스트리밍 중계 | Python 3.13+, Django 6.x, DRF | `backend/` |
| Database | 사용자 정보, 대화 세션(ChatSession), 메시지 내역(ChatMessage) 저장 | PostgreSQL / SQLite | `backend/models.py` |
| AI / LLM | 프롬프트 수신, 대화 문맥(Context) 파악 및 Chunk 단위 비동기 응답 반환 | OpenAI API | `backend/chat/services.py` |
| Deploy / Web | Nginx 경로 라우팅, SSL, Docker 컨테이너 실행 환경 | Nginx, Docker Compose | `deploy/`, `docker-compose.yml` |

## 10. LLM 연동 명세

### 10.1 입출력 규격 및 비동기 스트리밍 호출 명세

* **호출 방식**: Django의 `StreamingHttpResponse`를 활용한 Server-Sent Events (SSE) 전달 방식.
* **요청 (Request Payload)**:
  ```json
  {
    "session_id": "uuid-v4-string",
    "message": "사용자가 입력한 질문 텍스트",
    "context_depth": 5
  }
* **응답(SSE Stream Chunk Format)**:
  ```Plaintext
  event: message
  data: {"chunk": "안녕", "is_end": false}

  event: message
  data: {"chunk": "하세요!", "is_end": false}

  event: message
  data: {"chunk": "", "is_end": true, "session_title": "자동 생성된 제목"}

### 10.2 LLM 예외 처리 및 대처 방안
| 예외 상황 | 발생 원인 | 시스템 대응 방안
|---|---|---|
| 타임아웃 | OpenAI API 응답 지연 | 사용자 화면에 "답변 생성이 지연되고 있습니다. 잠시 후 재시도 해주세요." 메시지 표시 |
| API Quota 초과 | OpenAI API 한계 도달 | HTTP 429 응답 처리 및 "시스템 요청 한도를 초과했습니다." 안내 메시지 반환 |
| 네트워크 세션 끊김 | SSE 연결 클라이언트 중단 | 백엔드에서 Stream 객체를 소멸시키고 DB에는 그때까지 생성된 메시지 부분 저장 | 
| 민감정보/블라인드 | LLM 정책 위반 프롬프트 | "안전 정책에 따라 답변을 생성할 수 없습니다." 기본 텍스트 응답 대체 |
