## 3. 세부 유즈케이스 명세서

### UC-01. 사용자 회원가입 및 로그인

**유즈케이스 이름:** 사용자 회원가입 및 로그인  
**목적:** 사용자가 서비스 접근을 위해 계정을 등록하고 JWT 인증 토큰을 발급받는다.  
**주요 행위자:** 사용자 (Primary Actor)  
**사전 조건:** 사용자가 로그인/회원가입 페이지(`UI-001`)에 접속해 있다.  
**사후 조건:** JWT Access Token 및 Refresh Token이 발급되어 클라이언트에 저장되고, 메인 대화 화면(`UI-002`)으로 이동한다.

**주요 흐름 (Main Flow):**
1. 사용자는 회원가입 폼에 아이디, 이메일, 비밀번호를 입력하고 가입을 요청한다.
2. 시스템은 중복 검증 후 계정을 생성한다. (`FR-AUTH-001`)
3. 사용자는 생성된 계정 정보(아이디, 비밀번호)를 입력하고 '로그인' 버튼을 클릭한다.
4. 시스템은 계정 정보를 검증하고 Access Token과 Refresh Token을 발급하여 반환한다. (`FR-AUTH-002`)
5. 클라이언트는 토큰을 저장하고 메인 대화 화면(`UI-002`)으로 이동시킨다.

**대체 흐름 (Alternative Flow):**
* **4a. Access Token 만료 후 자동 갱신:**
  1. 사용자가 서비스 이용 중 Access Token이 만료되어 API 호출 시 401 Unauthorized 에러가 발생한다.
  2. Axios Interceptor가 이를 감지하여 Refresh Token으로 재발급 API를 자동 호출한다. (`FR-AUTH-003`)
  3. 토큰 재발급 성공 시 중단되었던 사용자 요청을 재시도한다.

**예외 흐름 (Exception Flow):**
* **2a. 회원가입 중복 오류:** 이미 존재하거나 형식에 맞지 않는 이메일/아이디 입력 시, 시스템은 경고 메시지를 표시하고 입력 단계에 머무른다.
* **4b. 로그인 인증 실패:** 아이디 또는 비밀번호가 불일치할 경우, 시스템은 에러 메시지를 노출하고 로그인 페이지를 유지한다.

### UC-02. LLM 대화 생성 및 스트리밍 답변 수신

**유즈케이스 이름:** LLM 대화 생성 및 스트리밍 답변 수신  
**목적:** 사용자가 질문을 전송하면 실시간(SSE) 타이핑 효과로 LLM의 답변을 수신하고 대화를 이어간다.  
**주요 행위자:** 사용자 (Primary Actor), 외부 LLM API (Secondary Actor)  
**사전 조건:** 사용자가 로그인되어 있으며 메인 대화 화면(`UI-002`)에 위치한다.  
**사후 조건:** 질문과 생성된 답변이 DB(`DATA-MESSAGE`)에 저장되고 화면에 출력된다.

**주요 흐름 (Main Flow):**
1. 사용자는 채팅 입력창(Textarea)에 질문을 입력하고 전송 버튼을 누르거나 Enter 키를 입력한다.
2. 사용자가 첫 질문을 입력한 경우, 시스템은 신규 대화 세션(`DATA-SESSION`)을 자동 생성하고 첫 질문을 기반으로 세션 제목을 부여한다. (`FR-LLM-003`)
3. 시스템은 최근 N개의 이전 대화 히스토리를 Context로 구성하여 외부 LLM API를 비동기 호출한다. (`FR-LLM-002`)
4. 백엔드는 LLM으로부터 수신되는 Chunk 데이터를 SSE(`StreamingHttpResponse`) 방식으로 클라이언트에 실시간 전송한다. (`FR-LLM-001`)
5. 클라이언트는 Chunk가 도착할 때마다 메시지 창을 갱신하며 화면 스크롤을 최하단으로 자동 이동(Auto-scroll)시킨다. (`NFR-UI-003`)
6. 스트리밍이 완료되면 답변 수신 상태를 종료하고 전송 버튼을 다시 활성화한다.

**대체 흐름 (Alternative Flow):**
* **1a. 모바일 기기 접속 시:**
  1. 모바일 화면에서 질문 입력창 터치 시 화면 키보드가 올라오며 뷰포트 크기가 조절된다. (`NFR-UI-004`)
  2. 사용자는 가림 현상 없이 입력창과 이전 대화 내용을 확인하며 질문을 전송한다.

**예외 흐름 (Exception Flow):**
* **3a. 외부 LLM API 타임아웃 / 응답 지연:**
  1. 외부 LLM 응답 시작 시간(TTFB)이 설정된 한도(2.5초)를 초과하면 타임아웃이 발생한다.
  2. 시스템은 "답변 생성이 지연되고 있습니다. 잠시 후 다시 시도해 주세요." 안내 메시지를 출력한다.
* **3b. API Quota 초과 (HTTP 429):**
  1. 사용량 초과 에러 발생 시, 시스템은 "일일 요청 한도를 초과했습니다." 시스템 안내 메시지를 노출한다.
* **4a. 스트리밍 도중 네트워크 연결 끊김:**
  1. SSE 연결이 끊어지면 백엔드는 스트림을 소멸시키고, DB에는 연결 중단 전까지 생성된 메시지 부분만 저장한다.

### UC-03. 대화 세션 및 이력 관리

**유즈케이스 이름:** 대화 세션 및 이력 관리  
**목적:** 사용자가 이전 대화 목록을 확인하고, 과거 대화 세션을 불러오거나 불필요한 세션을 삭제한다.  
**주요 행위자:** 사용자 (Primary Actor)  
**사전 조건:** 사용자가 로그인되어 상태이다.  
**사후 조건:** 선택한 대화 세션의 이전 메시지 내역이 대화창에 렌더링되거나 지정 세션이 삭제된다.

**주요 흐름 (Main Flow):**
1. 사용자는 사이드바(`UI-003`)에서 과거 대화 세션 목록을 확인한다. (`FR-HIST-001`)
2. 사용자가 특정 대화 세션 항목을 클릭한다.
3. 백엔드는 해당 세션의 전체 메시지 이력(`DATA-MESSAGE`)을 조회하여 반환한다.
4. 클라이언트는 불러온 메시지 내역을 채팅창(`UI-002`)에 순서대로 출력한다.

**대체 흐름 (Alternative Flow):**
* **1a. 모바일/태블릿 화면 접속 시:**
  1. 화면 상단의 햄버거 메뉴 버튼을 클릭하여 슬라이딩 Drawer 메뉴로 사이드바를 연다. (`NFR-UI-002`)
  2. 대화 세션을 선택하거나 바깥 영역을 터치하면 Drawer가 자동으로 닫힌다.
* **2a. 대화 세션 삭제:**
  1. 사용자가 대화 세션 항목 옆의 '삭제' 아이콘을 클릭한다.
  2. 확인 팝업 승인 시 시스템은 해당 세션과 관련 메시지를 삭제 처리한다. (`FR-LLM-004`)
  3. 메인 화면은 빈 대화창(새 대화 시작 상태)으로 초기화된다.

**예외 흐름 (Exception Flow):**
* **3a. 존재하지 않거나 권한이 없는 세션 접근:**
  1. 타인의 세션 ID로 접근을 시도할 경우, 403 Forbidden 에러와 함께 "접근 권한이 없습니다." 메시지를 표시하고 기본 메인 화면으로 이동시킨다.

### UC-04. 마이페이지 및 편의 기능

**유즈케이스 이름:** 마이페이지 및 편의 기능  
**목적:** 프로필 관리, 대화 이용 통계 확인 및 답변 내 코드 복사 등 부가 편의 기능을 이용한다.  
**주요 행위자:** 사용자 (Primary Actor)  
**사전 조건:** 로그인 완료 후 서비스 내 주요 화면에 위치한다.  
**사후 조건:** 프로필 정보가 변경되거나 선택한 코드가 클립보드에 복사된다.

**주요 흐름 (Main Flow):**
1. **코드 복사:** 챗봇 답변 중 마크다운 코드 블록 우측 상단의 '복사' 버튼을 클릭하면 해당 코드가 클립보드에 복사된다. (`FR-UI-001`)
2. **마이페이지 이동:** 상단 프로필 메뉴를 통해 마이페이지(`UI-005`)로 이동한다.
3. **통계 조회:** 사용자는 총 수행 대화 건수 등 간이 통계 수치 카드를 확인한다. (`FR-MY-002`)
4. **프로필 수정:** 비밀번호나 사용자 정보를 수정하고 저장한다. (`FR-MY-001`)

**대체 흐름 (Alternative Flow):**
* **1a. 모바일에서 코드 및 테이블 조회:**
  1. 긴 코드나 테이블이 포함된 답변 출력 시, 가로 스크롤(`overflow-x: auto`)이 생성되어 화면 깨짐 없이 가로로 스와이프하여 내용을 확인한다. (`NFR-UI-005`)

**예외 흐름 (Exception Flow):**
* **4a. 프로필 수정 검증 실패:** 현재 비밀번호 불일치 또는 비밀번호 규칙 위반 시 변경이 취소되고 에러 메시지가 출력된다.
