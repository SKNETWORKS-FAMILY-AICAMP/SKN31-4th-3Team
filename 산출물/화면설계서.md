가이드(`3-2메뉴구조도예.md`) 기준을 준수하여, 본 서비스의 정보 구조를 레벨 1부터 레벨 3까지 계층별로 정의한다.

| 레벨 1 (영역) | 레벨 2 (메인 메뉴) | 레벨 3 (하위 화면 / 기능) | 관련 화면 ID | 관련 API / 백엔드 모듈 |
|---|---|---|---|---|
| **비인증 영역** | 회원가입 | 회원가입 폼, 약관 동의, 가입 완료 | UI-001 | `POST /api/auth/signup/` |
| | 로그인 | 아이디/비밀번호 입력, JWT 발급 | UI-001 | `POST /api/auth/login/` |
| **인증 영역** | 메인 챗봇 | 신규 대화 시작, 자연어 질문 입력 | UI-002 | `POST /api/chat/sessions/` |
| | | SSE 실시간 스트리밍 답변 수신 | UI-002 | `GET/POST /api/chat/stream/` |
| | | 마크다운 코드 블록 & 복사 | UI-004 | Frontend Component |
| | 대화 이력 | 과거 대화 세션 목록 (사이드바/Drawer) | UI-003 | `GET /api/chat/sessions/` |
| | | 세션별 상세 메시지 내역 조회 | UI-003 | `GET /api/chat/sessions/{id}/messages/` |
| | | 대화 세션 삭제 | UI-003 | `DELETE /api/chat/sessions/{id}/` |
| | 마이페이지 | 사용자 프로필 정보 조회 / 수정 | UI-005 | `GET/PUT /api/users/me/` |
| | | 대화 이용 통계 카드 | UI-005 | `GET /api/users/me/stats/` |
| | | 로그아웃 | UI-001 | `POST /api/auth/logout/` |

## 3. 화면 - 백엔드(MVT/DRF) 및 요구사항 매핑 정합성표

각 화면이 요구사항 ID (`FR-*`, `NFR-*`) 및 백엔드 REST API 엔드포인트와 정합성을 이루도록 매핑한다.

| 화면 ID | 화면명 | 접근 권한 | 연결 요구사항 ID | 연결 백엔드 View / API |
|---|---|---|---|---|
| **UI-001** | 로그인 / 회원가입 | ALL (Public) | FR-AUTH-001, FR-AUTH-002, FR-AUTH-003 | `users.views.LoginView`, `SignupView` |
| **UI-002** | 메인 챗봇 화면 | USER (Protected) | FR-LLM-001, FR-LLM-002, FR-LLM-003, NFR-UI-003 | `chat.views.ChatStreamView` (SSE) |
| **UI-003** | 대화 이력 (사이드바) | USER (Protected) | FR-HIST-001, FR-LLM-004, NFR-UI-002 | `chat.views.ChatSessionViewSet` |
| **UI-004** | 메시지 및 코드 블록 | USER (Protected) | FR-UI-001, NFR-UI-005 | React `CodeBlock` / `MarkdownRenderer` |
| **UI-005** | 마이페이지 | USER (Protected) | FR-MY-001, FR-MY-002 | `users.views.UserProfileView` |
