## 🔴 Blockers / Issues (이슈 및 해결)
- **이슈 1:** Swagger UI 인증 헤더 형식이 맞지 않아 `401 Unauthorized` (`bad_authorization_header`) 발생
  - **해결:** Authorize 창에 `Bearer` 단어와 토큰을 중복 입력하여 헤더에 `Bearer Bearer <token>` 형태로 전달된 원인 파악. `settings.py` 내 `SPECTACULAR_SETTINGS`에 `SWAGGER_UI_SETTINGS` 설정을 추가하여 토큰 값만 입력하도록 개선하여 해결 완료.
- **이슈 2:** 대화방 생성 시 `OperationalError: no such table: chat_chatsession` (500 Internal Server Error) 발생
  - **해결:** `chat` 앱의 데이터베이스 마이그레이션 파일이 실제 SQLite DB에 반영되지 않은 상태 확인. `python manage.py makemigrations chat` 및 `python manage.py migrate` 명령어를 재실행하여 해결 완료.
- **이슈 3:** JWT Access Token 만료로 인한 `token_not_valid` 에러 발생
  - **해결:** SimpleJWT 기본 Access Token 만료 시간(5분) 경과 원인 확인 후 재로그인을 통해 새 토큰을 발급받아 테스트 완수. 개발 환경에서의 편의성을 위해 `settings.py` 내 `ACCESS_TOKEN_LIFETIME` 설정 조정 방안 정리.
